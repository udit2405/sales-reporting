# Sales Reporting (Google Apps Script)

Complete app in `appscript/`: `Code.gs` (single file). Form with store dropdown (live from the sheet) and the 11 sale fields; Submit writes straight into that store's row.

Setup: sheet → Extensions → Apps Script → paste Code.gs → Deploy → New deployment → Web app (Execute as *Me*, access *Anyone*) → share the URL.
